# P9 - Performance and hardening
Only after core features are reliable, and only from measurements: partial-transcription latency, CPU vs GPU benchmarks, warm-up/unload controls, output and search caching, resource limits, multilingual quality, large-transcript search, model download verification, recovery without restart.

# P10 - Out of scope (do not build)
Team spaces, cloud sync, shared notes, managed cloud providers, enterprise auth/policy. These need external infrastructure. Keep the data model extensible but build no backend for hypothetical future features, and do not let them delay the local core.
